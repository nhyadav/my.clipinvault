Changelog

What's new, what's fixed, and what's next for ClipinVault.

v1.3.3 June 28, 2026 Latest
  1. Manual clip creation: create new clips directly inside ClipinVault without copying from another application — click New Clip in the sidebar, type your content, pick a type, and save.
  2. Edit clip content: fix typos, sanitise captured text, or rewrite entries in-place using the new Edit Content panel — supported for all types except Secret and Image.
  3. Alphabetic MFA / OTP detection: the auto-detector now recognises alphanumeric one-time codes such as MGA-TGP and JTKASF in addition to the existing six-digit numeric TOTP codes.
  4. Line-number editor: the New Clip content area shows live line numbers, supports Tab-to-indent (2 spaces), and auto-indents on Enter — no extra dependencies.
Download for Windows Download for Ubuntu
v1.3.2 June 28, 2026 Previous Release
  1. Import & Export: export selected clip types (text, code, SQL, JSON, URL, command) to a portable .clipbundle file; secrets export to a separate plaintext bundle for secure device-to-device transfer; import merges with deduplication — no duplicates, ever.
  2. Export by date range: filter your vault before exporting — choose a custom time window to ship only the clips from a specific period rather than your full history.
  3. Selective import: choose which content types to merge from a .clipbundle file before committing — bring only code and URL entries, or exclude MFA and image entries.
  4. Import merge control: new option to keep both entries when an imported item matches an existing clip, instead of always skipping duplicates.
  5. Content length upgrade: clipboard capture limit raised to 5 MB per entry, enabling capture of large database exports, verbose log outputs, and extended minified payloads without truncation.
  6. Sort by usage count: clips can now be sorted by how often they have been used, surfacing your most-reached-for content at the top of the list.
  7. Usage count in list view: every clip now displays its usage count directly in the list, giving you an at-a-glance read on how frequently each entry is used.
v1.3.1 March 25, 2026 Previous Release
  1. Added tag-based content types: URL, Code, JSON, SQL, Command, MFA, Secrets, and Image clips alongside regular text.
  2. Clipboard now captures formatting — pastes retain the original structure of copied content.
  3. New preview button lets you view the full content of any clip before pasting.
  4. Paste options: choose to paste with or without formatting depending on the target.
  5. Image clips now support download and export — save captured screenshots directly from the vault.
  6. Full space utilization with a row-based layout for better readability across screen sizes.
  7. Auto-clean scheduler: unused clips with zero usage are cleared automatically to keep ClipinVault stable and lean.
v1.2.3 February 28, 2026 Previous Release
  1. Change content type from text to secret to encrypt data — use this only for credentials. Encryption key is stored in the Windows Key Manager or equivalent on other OS.
  2. Pin content to keep it visible on top of the list at all times.
  3. Filter and search are now available across all clips.
  4. Set a title for any content to remember context, such as which account's password was copied.
  5. Paste any content anywhere with a single click.
  6. Supports three content types: Text, Secret, and Image.
  7. Captures screenshots and image copies alongside plain text.
