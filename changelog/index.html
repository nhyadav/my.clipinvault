Changelog

What's new, what's fixed, and what's next for ClipinVault.

v1.3.3 The Editing Update June 28, 2026 Latest
  • Manual Creation: Create clips directly inside the app — click New Clip in the sidebar, type your content, pick a type, and save.
  • In-Place Editing: Fix typos or sanitise captured text using the new Edit Content panel — supported for all types except Secret and Image.
  • Smart OTP Detection: Alphanumeric one-time codes like MGA-TGP and JTKASF now detected alongside numeric TOTP codes.
  • Line-Number Editor: The New Clip editor shows live line numbers, supports Tab-to-indent (2 spaces), and auto-indents on Enter.
Download for Windows Download for Ubuntu
v1.3.2 The Export Update May 15, 2026 Previous Release
  • Portable Bundles: Export selected clip types to a .clipbundle file for device-to-device transfer or backup — secrets go to a separate plaintext bundle.
  • Date Range Export: Filter your vault by time window before exporting — ship only the clips from a specific period.
  • Selective Import: Choose which content types to merge from a bundle before committing — bring only what you need.
  • Merge Control: New option to keep both entries when an imported clip matches an existing one, instead of always skipping duplicates.
  • 5 MB Capture Limit: Raised limit enables capture of large database exports, verbose logs, and extended minified payloads.
  • Sort by Usage: Surface your most-reached-for clips by sorting the list by usage frequency.
  • Usage Count Display: Every clip now shows its usage count directly in the list view.
v1.3.1 The Content Types Update March 25, 2026 Previous Release
  • Content Types: Introduced URL, Code, JSON, SQL, Command, MFA, Secret, and Image detection alongside regular text.
  • Formatting Capture: Pastes now retain the original structure of copied content.
  • Full-Content Preview: View the complete content of any clip before pasting.
  • Paste Options: Choose to paste with or without formatting depending on the target application.
  • Image Export: Download and export captured screenshots directly from the vault.
  • Responsive Layout: Row-based full-space layout for better readability across screen sizes.
  • Auto-Clean: Zero-usage clips are cleared automatically to keep the vault lean.
v1.2.3 The Security Update February 28, 2026 Previous Release
  • Secret Mode: Convert any clip to AES-256 encrypted — key stored in OS credential manager (Windows Credential Manager or equivalent).
  • Pin to Top: Pin any clip to keep it permanently visible at the top of the list.
  • Filter & Search: Search and filter across all clips by content or type.
  • Custom Titles: Name any clip to remember its context — e.g., which account's password was saved.
  • One-Click Paste: Paste any content anywhere directly from the vault.
  • Three Core Types: Text, Secret, and Image clips fully supported.
  • Screenshot Capture: Automatically captures screenshots and image copies alongside plain text.
